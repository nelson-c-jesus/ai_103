# Generative AI and agents

1. Generative AI is based in Large Language Models (LLMs) with the ability to generate original responses to natural language prompts.
Examples:
    - Power interactive chat applications
    - AI-assisted content creation.

2. Is used as the foundation for Agentic AI solutions. A combination between LLMs with focused **instructions** that defines responsabilities and **tools** that the agent use to find relevant informations or automate tasks for which it is responsible.
