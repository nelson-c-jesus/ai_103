# Natural language processing (NLP)

1. NLP makes use of statistical and semantic models to make sense of language in:
    - Documents
    - E-mails
    - Social media
    - Messages
    - Other sources of text

2. Text analysis can benefit from statistical NLP like:
    - Term-frequency algorithms (TF-IDF or Inverse TF-IDF)
    - Text classification
    - Sentiment analysis
    - Summarization
