# AI-103 — Azure AI Apps and Agents Developer Associate

Repositório de estudo e documentação técnica baseado no percurso oficial da Microsoft Learn para a certificação **AI-103 — Azure AI Apps and Agents Developer Associate**.

---

## Sobre

Este repositório reúne notas, resumos, conceitos e exemplos relacionados ao desenvolvimento de aplicações de Inteligência Artificial Generativa no ecossistema Azure.

O conteúdo foi estruturado com base na documentação oficial da Microsoft Learn e cobre tópicos como:

* Azure AI Foundry
* Azure OpenAI
* Modelos generativos
* Prompt Engineering
* RAG (Retrieval-Augmented Generation)
* AI Agents
* Responses API
* ChatCompletions API
* Avaliação de modelos
* Responsible AI

---

## Objetivos

* Apoiar a preparação para a certificação AI-103
* Consolidar conhecimento sobre Azure AI
* Criar uma base de consulta técnica
* Centralizar exemplos e notas de estudo
